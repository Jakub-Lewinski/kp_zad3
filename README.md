# kp_zad3

### 1. Użytkownik częściowo odpowiada za poprawność wpisywanych zakresów dni.
- Program nie obsługuje przypadków: gdy zakres jest odwrócony (nd-pt); inne.
### 2. Pory dnia nie są ustawiane automatycznie, trzeba wpisać ręcznie. Liczba pór musi być równa liczbie dni w zakresach.
### 3. Obsługa CSV:
- Funkcje zapisu i odczytu wymagają podania jako argumentu ścieżki do docelowego katalogu.
- Zapis i odczyt odbywają się tylko gdy dana ścieżka i plik istnieją.
